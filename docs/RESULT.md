# RESULT.md — systolic2x2（2×2 输出驻留脉动 MAC 阵列）

模式：ENGINEERING_AUTONOMY。本文件所有数字均来自 logs/ 内的实际日志；最终 PASS/FAIL 由 Lead 独立判定，本文只是实现 Agent 的自述。

## 1. 架构与关键参数
- 结构：2×2 个 PE（`pe` 子模块例化 4 个），每个 PE 一个 8×8 有符号乘法器 + 32 位累加器；**输出驻留（output-stationary）脉动阵列**，A 逐拍右移、B 逐拍下移，C 驻留在各 PE 累加器；第 1 行 A 与第 1 列 B 在模块内部各打一拍产生偏斜。
- 端口：clk、rst_n（异步低有效）、in_valid、a0/a1/b0/b1（8 位有符号）；c00/c01/c10/c11（32 位有符号）、out_valid。一组矩阵占连续 2 个 in_valid 拍（k=0、k=1）。
- 组间隔 II=4，吞吐 1 矩阵/4 周期，延迟：第 1 输入拍后第 4 周期出结果。
- 每个 C 元素首次有效拍（以第 1 输入拍为周期 0）：c00=周期 2，c01=周期 3，c10=周期 3，c11=周期 4；四元素同时稳定且 out_valid=1 的唯一周期为周期 4（out_valid 为 1 拍脉冲，第 g 组在周期 4g+4）。
- 架构选择：选输出驻留、c 直连累加器（FF 最少、控制最简）；放弃输出保持寄存器方案（估算 FF≈440，超 400 预算）、权重驻留（需预载与输出对齐）、行广播组合阵列（非脉动）。详见 SPEC.md 第 6 节。
- FF 预算：SPEC 估算≈182，实测 182，预算≤400。

## 2. 验证
- RTL 仿真（iverilog 12.0，`-Wall -g2005` 零警告）：TB 共 **1795 项检查，errors=0，vvp 退出码 0**。向量 80 组 = 16 组定向（全127、全-128、127×-128、-128×127、单位阵、零阵、混合符号等）+ 64 组随机，**随机种子 20261111**（golden.py 生成 vectors.txt/vectors.hex）。
- TB 分四阶段：80 组间隔 4；80 组间隔 7；异步复位发生在组中间后接 6 组；20 组间隔 5。逐周期比对 out_valid 与 4 个 C 元素，out_valid 共 186 次脉冲，与预期一致；in_valid=0 时数据脚灌随机值，要求被忽略。
- golden.py：7 个手算断言全过；周期级脉动模型在 II=4、II=7 下与矩阵乘法及 SPEC 时序一致。
- VCD 解析（parse_vcd.py，独立于 TB）：**11 个采样点、50 项检查全部 PASS**（复位点；c00/c01/c10/c11 首次有效拍及其前一拍的部分积；PE 间传递周期 1、周期 2；连续两组输出点；80 组 out_valid 脉冲串；80 组×4 元素共 320 个 C 逐一比对），结果见 vcd_result.txt。
- 变异测试（只在 mutants/ 副本上做，交付 RTL MD5 前后均为 d80787605228454f9df64922f8dda8a3）：
  - 数据类：PE00 漏加 k=1 乘积 → **errors=161，vvp 退出码 1**，检出。
  - 控制类：out_valid 提前 1 拍 → **errors=372，vvp 退出码 1**，检出。
- 门级仿真：同一 TB（未改动）对 yosys 网表仿真，**1795 项检查，errors=0，退出码 0**，与 RTL 一致。

## 3. 综合
- 工具：Yosys 0.33（git 2584903a060）；脚本 synth.ys（`synth -flatten` + `stat`）。
- 综合前内存（free -m）：total 7934 / used 7464 / free 125 / available 469 MiB；按 available≥300 MiB 判据放行（free 列仅 125 MiB，已如实记录）。
- 结果：**通用单元 3032，触发器 182**（$_DFFE_PN0P_ 129 + $_DFF_PN0_ 53），预算 ≤8000 / ≤400，均满足。单元分类见 synth_stat.txt。
- 耗时 1.58 s；峰值内存 34.5 MiB（Python resource.getrusage(RUSAGE_CHILDREN).ru_maxrss，yosys 用 taskset -c 0,1 启动）。
- 无工艺库，以上仅为通用单元统计，不代表面积、功耗或 Fmax。
